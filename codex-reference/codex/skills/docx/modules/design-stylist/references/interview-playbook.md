# Interview Playbook

Use this sequence when the user wants a first pass.

1. Start:
   - "Tell me the feeling you want in one sentence. If this document spoke, what would it sound like?"
   - "Who is the primary reader and what action do you want from them?"

2. Constrain aesthetics:
   - "Which three adjectives best describe the tone?" (e.g., trusted, premium, playful)
   - "What should it avoid? (corporate boring, too loud, too dark, etc.)"
   - "Print, PDF, screen, or mixed?"

3. Material style anchors:
   - "Can you name 1-2 reference documents or brands and what you like/dislike in each?"
   - "Are you comfortable with bold color accents, or do you want near-monochrome?"

4. Visual interpretation:
   - Offer 2 quick interpretations from the gathered inputs, each with
     - a palette direction
     - typography choice
     - section rhythm
   - Ask: "Which version feels closest?"

5. Finalization:
   - convert chosen interpretation into manifest tokens
   - list any unresolved items as `design_questions`
   - set `confidence` to low if unresolved questions remain
