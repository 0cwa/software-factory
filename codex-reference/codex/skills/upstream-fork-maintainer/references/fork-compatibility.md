# Fork Compatibility

State fork intent before judging delta. Classify changes as upstream-only, fork-only, equivalent, conflicting, obsolete, or unknown. For every integration candidate record prerequisites, affected intentional behavior, configuration or adapter alternatives, conflict cost, future mergeability, and validation.

Branch archaeology is read-only until explicitly authorized. Stable commit IDs and patch content are stronger evidence than branch names. Preserve unique work before any branch deletion or history rewrite. Domain-specific skills own build and compatibility semantics; GitHub skills own remote publication.
