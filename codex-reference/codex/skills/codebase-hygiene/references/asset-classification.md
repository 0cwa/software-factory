# Asset Classification

- Canonical source: authoritative input edited directly.
- Generated: reproducible output whose generator and inputs are known.
- Cache: disposable acceleration state.
- Private/local: machine- or user-specific data that should not be published.
- Duplicate: redundant copy with a proven canonical owner.
- Obsolete: no supported producer, consumer, compatibility, archival, or recovery role.
- Archive candidate: not active but worth retaining outside the active surface.
- Unknown: insufficient evidence; retain until resolved.

Record producer, consumers, tracked state, sensitivity, regeneration command, canonical owner, proposed action, recovery method, and verification for every non-retain action.
