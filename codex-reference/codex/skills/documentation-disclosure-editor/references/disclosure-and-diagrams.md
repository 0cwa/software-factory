# Disclosure and Diagram Rubric

Keep orientation, prerequisites, warnings, decisions, and required actions visible. Good disclosure labels let readers predict the hidden content and preserve anchorable, searchable, accessible meaning.

Choose diagrams by explanatory job: flow for sequence, graph for relationships, state diagram for transitions, tree for hierarchy, table for exact comparison, timeline for change, and wireframe for spatial layout. Skip a diagram when concise prose or a table is clearer. Verify semantic accuracy, text alternatives, contrast, overflow, light and dark themes, and narrow widths.
