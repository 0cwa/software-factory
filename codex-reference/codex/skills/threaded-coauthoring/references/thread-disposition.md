# Thread Disposition

Use stable thread IDs and preserve source batch, anchor, author, response, target, dependencies, and duplicate links.

States: `open`, `direct-edit`, `accepted-proposal`, `agent-proposal`, `question`, `conflict`, `rejected`, `already-reflected`, and `integrated`. An integrated thread identifies the canonical destination and validation evidence. A duplicate points to the primary thread but remains counted. Completion requires every thread integrated, rejected, already reflected, or explicitly unresolved with an owner.
