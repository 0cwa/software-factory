# Thin-Slice Rubric

Score options relatively, not with false numeric precision.

Prefer slices with high direct user value, small bounded effort, low irreversible risk, easy rollback, fast learning, and a complete acceptance path. Mandatory safety, compatibility, and data-integrity gates are constraints rather than optional score dimensions.

A valid slice has one user-visible outcome, real inputs and outputs, runnable acceptance checks, a stop condition, and named deferrals. An upgrade seam is a documented boundary where deferred capability can attach without building it now.
